# 💰 Sistema de Controle Financeiro

Este projeto consiste em um mini sistema de controle de finanças pessoais desenvolvido em Python. O programa é executado pelo terminal e funciona por meio de entradas do usuário. É possível cadastrar receitas e despesas, armazenar as movimentações em um histórico, calcular o saldo atual e classificar a situação financeira do usuário com base no saldo disponível.

## Funcionalidades

- Cadastro de Receitas
- Cadastro de Despesas
- Histórico de movimentações
- Atualização automática do saldo
- Cálculo do total de receitas e despesas
- Classificaçã:o da situação atual do saldo
- Validação das entradas do usuário
- Interface via terminal

## Tecnologias utilizada

- Python 3

## Como executar

1.  Antes de executar, certifique-se de ter o Python instalado.
2.  Clone o repositório pelo Git ou baixe o projeto em .zip.
3.  Abra o terminal e acesse a pasta onde está o projeto.
4.  Execute o arquivo principal com o comando: programa_organização_financeira.py
